# Contributing

Issues and pull requests are welcome.

- Open an issue first for a large change, so we agree on the design before the code.
- Run `Scripts/install_hooks.sh` once per clone, and `bash Scripts/check.sh` before you push.
- Keep a pull request to one change, and write commit subjects in the imperative mood.
- Report security problems through [SECURITY.md](SECURITY.md), never in a public issue.

See [docs/development.md](docs/development.md) for build, test and QA details.
