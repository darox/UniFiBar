## 2. Performance

The retained change reduces icon-copy process launches from ten to one.
The benchmark runs the actual shared assembly function against tracked assets,
with a test double for `iconutil`. It measures shell staging, not app runtime.
Each result is the median of seven round means, twenty bundles per round,
after two warm-up bundles. Each version passes the same content checks.

| Run order | Before | After | Reduction |
| --- | ---: | ---: | ---: |

| After, then before | 28.91 ms | 19.40 ms | 32.9% |

python3 Tests/test_build_bundle.py --script /tmp/unifibar-audit.VQrvlP/build_common-before.sh --benchmark

App-runtime performance remains blocked on macOS. One candidate is
`WiFiStatus.updateSessions()`: each session scans devices and converts MAC
addresses to lowercase again. The fetch caps permit 1,000 sessions and 500
devices. A lookup table could help, but no unmeasured app optimization was kept.
Controller request latency also needs a real or replayable controller fixture.
